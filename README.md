# rkn-pd-operator

Скилл для AI-агентов (Claude Code, Codex и других, которые понимают формат
`SKILL.md`) по регистрации в реестре операторов персональных данных
Роскомнадзора:

- уведомление об обработке ПД (ст. 22 152-ФЗ);
- уведомление о трансграничной передаче (ст. 12);
- изменение сведений и прекращение обработки.

Главный принцип: в уведомлении описывается **реальная** обработка данных.
Поэтому скилл сначала проводит инвентаризацию: какие данные, где хранятся,
кому передаются. Поля формы заполняются только после неё.

## Состав

- `SKILL.md` — основной сценарий работы агента.
- `references/` — поля формы, правовые факты, трансграничная передача,
  инвентаризация данных, действия после подачи.
- `evals/` — тестовый сценарий для проверки скилла.

## Установка

```bash
git clone https://github.com/mccarttmonroe19963/rkn-pd-operator.git
ln -s "$PWD/rkn-pd-operator" ~/.claude/skills/rkn-pd-operator   # Claude Code
ln -s "$PWD/rkn-pd-operator" ~/.agents/skills/rkn-pd-operator   # Codex и др.
```

Обновление: `git pull` в папке репозитория.

## Дисклеймер

Это не юридическая консультация. Перед подачей сверяйте требования с
актуальными нормативными актами и сайтом pd.rkn.gov.ru.
